# Архитектура LLM-Control-v2 — Краткое резюме

## Что это

LLM-Control v2 — десктопное приложение для управления удалённым RTX-сервером с llama-server. Позволяет сканировать модели, генерировать конфиги и управлять сервером через SSH.

## Основные компоненты

### UI Layer
- **MainWindow** — главное окно, координация вкладок
- **ScannerWidget** — сканирование `.gguf` моделей
- **ConfigWidget** — генерация и редактирование `.mod` файлов
- **ServerWidget** — управление сервером, WoL, SSH

### Services Layer
- **model_scanner** — поиск файлов по расширению
- **mod_generator** — генерация `.mod` файлов, преобразование путей
- **system_monitor** — мониторинг ресурсов по SSH
- **server_control** — локальный контроль процессов
- **ssh_setup** — настройка SSH-ключей

### Infrastructure
- SSH / Paramiko
- psutil
- PySide6

## Потоки работы

1. **Сканирование** → поиск моделей на диске
2. **Конфигурация** → генерация `.mod` файлов
3. **Управление** → SSH команды на сервер
4. **Мониторинг** → сбор метрик в реальном времени

## Проблемы

- Смешение UI и бизнес-логики
- Отсутствие тестов
- Проблемы безопасности
- Хардкод путей
- Отсутствие DI

## Рекомендации

1. Выделить бизнес-логику из UI
2. Добавить абстракции для SSH
3. Внедрить DI
4. Добавить тесты
5. Улучшить безопасность
