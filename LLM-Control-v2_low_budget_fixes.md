# Малобюджетные первоочередные правки для LLM-Control-v2

## Цель

Правки, которые можно сделать быстро, без изменения архитектуры, с минимальными рисками и без остановки работы приложения.

## 1. Логирование действий пользователя

**Что сделать:**
- Добавить логгер в main_ui.py, scanner_widget.py, config_widget.py, server_widget.py
- Логировать все действия: сканирование, выбор модели, сохранение конфига, команды на сервер
- Использовать существующий logging_config

**Почему важно:**
- Упрощает отладку
- Позволяет воспроизводить проблемы
- Даёт аудит действий

**Сложность:** 2/10
**Время:** 2-4 часа
