# Аналоги приложения LLM-Control v2

## Обзор

LLM-Control v2 — десктопное приложение PySide6 для управления удалённым RTX-сервером с llama-server: сканирование `.gguf` моделей, генерация `.mod` конфигов, удалённое управление через SSH/WoL, мониторинг ресурсов.

Аналогов с таким же набором функций нет в открытом доступе. Есть проекты с частичным пересечением функционала.

## Прямые аналоги по управлению llama-server

### 1. llmctl
**Репозиторий:** `https://github.com/tgrosshauser/llmctl`
**Тип:** CLI
**Функции:**
- Управление несколькими инстансами llama-server
- Старт/стоп/перезапуск
- Мониторинг статуса
- Управление конфигурацией

**Отличия от LLM-Control v2:**
- CLI, без GUI
- Нет сканирования моделей
- Нет WoL
- Нет авто-подбора параметров

**Использование в LLM-Control v2:**
Используется как backend для выполнения команд на сервере

### 2. llama-server-webui / llama-server-ui
**Репозитории:**
- `https://github.com/llama-server-webui/llama-server-webui`
- `https://github.com/llama-server-ui/llama-server-ui`

**Тип:** Веб-интерфейс
**Функции:**
- Управление инстансами llama-server
- Редактирование конфигов
- Мониторинг

**Отличия:**
- Веб, не десктоп
- Нет сканирования моделей
- Нет SSH

## Сравнение по архитектуре и технологиям

### LLM-Control v2
**Архитектура:**
- Десктопное приложение PySide6
- Трехслойная архитектура: UI → Services → Infrastructure
- Многопоточность через QThread
- Сигналы/слоты Qt

**Технологии:**
- Python 3.8+
- PySide6
- Paramiko для SSH
- psutil для мониторинга
- dotenv для конфигурации

**Плюсы:**
- Нативная интеграция с ОС
- Быстрая работа
- Полный контроль над функциями

**Минусы:**
- Платформо-зависимо
- Сложность установки
- Нет кроссплатформенности
